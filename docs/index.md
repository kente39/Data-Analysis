## 이 가이드는

식물(몬스테라·스투키·고무나무 등 6종)의 생육 데이터를 예제로, 데이터 분석의 전 과정을 실제 Python 코드로 배웁니다.

- **대상**: 통계·프로그래밍을 처음 접하는 분부터, 개념을 코드로 옮기고 싶은 분까지
- **데이터**: `plant_growth.csv` (5,000개체, [데이터 페이지](/data)에서 다운로드)
- **환경**: Jupyter Notebook 또는 Google Colab + Python 라이브러리
