# 8. 요즘 트렌드 — 기법의 변천사

Module 1~7에서 통계 검정, 머신러닝, 딥러닝까지 차례로 다뤘습니다. 이번 모듈은 새 코드를 배우는 대신, 지금까지 배운 기법들이 **과거부터 최신까지 어떻게 발전해 왔는지**, 그리고 **요즘 트렌드는 과거와 무엇이 다른지**를 지도처럼 훑습니다.

핵심 흐름은 한 문장으로 요약됩니다: **통계 규칙 → 머신러닝 → 딥러닝 → 파운데이션 모델.** 뒤로 갈수록 "사람이 규칙을 많이 정하던 방식"에서 "데이터로부터 스스로 학습하는 방식", 나아가 "**한 번 사전학습한 큰 모델을 재학습 없이 가져다 쓰는 방식**"으로 옮겨갑니다.

::: tip 이 모듈의 성격
8장은 실행 코드·수치보다 **개념과 역사, 모델 선택 관점** 위주입니다. 각 기법을 깊게 구현하기보다, "언제·왜 나왔고 무엇을 개선했는가"를 이해하는 데 목적이 있습니다.
:::

## 8-1. 표(tabular) 데이터 회귀·분류의 변천사

우리가 Module 1~7 내내 다룬 `plant_growth` 같은 **표 형태 데이터**의 회귀·분류는 이렇게 발전해 왔습니다.

-표 사진-

### ① 통계 규칙 기반 — 선형·로지스틱 회귀

가장 고전적인 출발점입니다(4·6장). 통계학에 뿌리를 둔 방법으로, 입력과 출력의 관계를 **수식(식의 계수)으로 추정**합니다.

**선형 회귀(Linear Regression)** 는 **선형 공간에서의 회귀** — 즉 입력이 커질수록 출력이 일정한 비율로 변한다고 보고 **직선(초평면)** 을 맞춥니다. 출력이 **연속값**(키·가격 등)일 때 씁니다.

**로지스틱 회귀(Logistic Regression)** 는 이름은 '회귀'지만 **분류**가 목적입니다. 선형식의 결과를 **sigmoid**에 통과시켜 **0~1 사이 확률**로 바꾸고, 기준(보통 0.5)을 넘으면 양성으로 분류합니다(7장 분류 출력층과 같은 원리).

- **유래** — 수백 년 된 최소제곱법(선형)과 20세기 통계학(로지스틱)에 기반.
- **강점** — 계수로 "어떤 변수가 얼마나 영향을 주는지" **해석이 쉽고**, 데이터가 적어도 안정적.
- **한계** — "관계가 선형"이라는 가정이 깨지면 성능이 떨어짐. 다만 우리 데이터처럼 관계가 실제로 선형에 가까우면(6장 Linear가 최고였듯) 여전히 강력.
- **주 활용처** — 효과·요인 분석(통계), 베이스라인 모델, 해석이 중요한 의료·사회과학.

### ② 트리 기반 앙상블 — RF, XGBoost, LightGBM, CatBoost

먼저 **결정 트리(Decision Tree)** 는 "이 변수가 X보다 큰가?" 같은 **예/아니오 질문을 단계적으로 나눠** 예측하는 모델입니다(사람의 판단 흐름과 비슷해 직관적). 단, 트리 하나는 데이터를 과하게 외워 **과적합**되기 쉽습니다. 그래서 **여러 트리를 모아(앙상블)** 약점을 보완한 것이 아래 모델들입니다.

- **Random Forest** — 데이터·변수를 무작위로 조금씩 바꿔 **수많은 트리를 독립적으로 만들고 투표/평균**. 과적합을 크게 줄이고 안정적(6장에서 사용).
- **XGBoost** — 트리를 **순차적으로** 만들되, 앞 트리가 틀린 부분을 다음 트리가 집중 보완하는 **부스팅**. 성능이 뛰어나 대회·실무에서 표준처럼 쓰임.
- **LightGBM** — XGBoost와 같은 부스팅이지만 **더 빠르고 메모리 효율적**이도록 개선(대용량 데이터에 유리).
- **CatBoost** — **범주형 변수**를 자동으로 잘 처리하도록 특화된 부스팅(인코딩 수고를 덜어줌).

- **유래** — 결정 트리(1980년대) → 배깅/랜덤포레스트(1990~2000년대) → 그래디언트 부스팅 계열(2010년대).
- **강점** — 비선형 관계·변수 간 상호작용을 자동으로 잡고, 전처리에 덜 민감하며 성능이 뛰어남.
- **한계** — 선형모델보다 해석이 어렵고 하이퍼파라미터 튜닝 필요.
- **주 활용처** — **표 데이터 실무의 사실상 1순위.** 금융·추천·순위예측·캐글 대회 등 광범위.

### ③ 딥러닝(표 전용) — Transformer, TabR

딥러닝은 원래 **이미지·자연어**에서 먼저 크게 성공했습니다. 공통 혁신은 사람이 특징을 일일이 설계하지 않아도 **데이터에서 특징을 스스로 뽑아낸다**는 점인데, 분야마다 핵심 구조가 다릅니다.

**CNN(합성곱 신경망) — 이미지.** 이미지는 수많은 픽셀이라 전부 직접 연결하면 비효율적입니다. CNN은 작은 **필터(커널)** 를 이미지 위에서 미끄러뜨리며 **지역적인 패턴**(모서리·선·질감)을 잡고, 층이 깊어질수록 그 조각들을 모아 **점점 복잡한 형태**(눈 → 얼굴)를 인식합니다. 핵심은 **"같은 필터를 전체에 재사용"**(파라미터 공유)해, 위치가 조금 달라도 같은 특징을 찾아낸다는 점입니다.

**Transformer — 자연어.** 문장은 **단어의 순서와 서로의 관계**가 중요합니다. Transformer는 **어텐션(attention)** 으로 "지금 이 단어가 문장 안의 **어떤 단어와 얼마나 관련 있는지**"를 가중치로 계산해, 멀리 떨어진 단어 사이의 관계까지 한 번에 반영합니다. RNN처럼 순서대로 처리하지 않고 **전체를 병렬로** 보기 때문에 빠르고, 긴 문맥을 잘 다룹니다. 오늘날 대규모 언어모델(GPT 등)의 토대이기도 합니다.

이 성공을 **표 데이터에도 적용**하려는 흐름이 생겼습니다. 하지만 표 데이터는 이미지·문장과 달리 **열마다 의미·단위가 제각각이고, 픽셀의 공간성이나 단어의 순서 같은 구조가 없어서** 그대로 옮기면 잘 안 됩니다. 그래서 표에 맞게 구조를 바꾼 모델들이 등장했습니다.

- **FT-Transformer** — 각 열(특성)을 토큰처럼 다뤄, **어텐션으로 "어떤 변수들이 서로 함께 작용하는지"** 를 학습하는 표 전용 트랜스포머.
- **TabR** — 신경망에 **최근접 이웃(KNN)** 아이디어를 결합해, 예측할 때 **"비슷한 과거 샘플"을 참고**하도록 만든 모델. 일부 데이터셋에서 부스팅을 넘어서기도 함.

- **강점** — 매우 크고 복잡한 표 데이터에서 잠재력.
- **한계** — 층·뉴런·에포크 등 조정할 게 많고 학습이 느림. **7장에서 확인했듯, 작고 단순한 표 데이터에서는 트리 앙상블을 넘어서지 못하는 경우가 많음.**
- **주 활용처** — 특성이 매우 많거나 대규모인 표 데이터, 다른 딥러닝 파이프라인과 결합할 때.

### ④ 파운데이션 모델 — TabPFN

가장 최신 흐름입니다. 지금까지는 **데이터셋마다 모델을 처음부터 새로 학습**했지만, **TabPFN**은 다릅니다 — 미리 거대한 모델을 **사전학습**해 두고, 새 데이터는 **재학습 없이 한 번의 계산으로 예측**합니다(대규모 언어모델의 인컨텍스트 학습과 같은 원리).

**원리를 직관적으로** 보면: TabPFN은 **엄청난 수의 가상(합성) 표 데이터셋**을 만들어 미리 학습해 둡니다. 그 과정에서 "표 데이터에서 입력이 이런 모양이면 결과는 대개 이런 식으로 분포·수렴한다"는 **표 데이터의 일반적 패턴 자체를 학습**합니다. 그래서 처음 보는 데이터가 들어와도, 학습해 둔 패턴에 비추어 **곧바로 예측**할 수 있습니다 — 매번 새로 훈련하지 않고요.

- **유래** — 2022년 등장, 2025년 개선판이 Nature에 발표되며 크게 주목.
- **강점** — **작은 표 데이터셋에서 재학습 없이** 빠르고 강력한 성능.
- **한계** — 아주 큰 데이터·특성 수에는 제약이 있으나, 최신 버전에서 점차 확장 중.
- **의미** — "데이터셋마다 처음부터 학습한다"는 오랜 전제를 깬 접근으로, 표 데이터에도 **파운데이션 모델 시대**가 열렸음을 보여줌.

::: warning 그래서 무엇을 써야 하나
발전 순서가 곧 "항상 최신이 최고"를 뜻하지는 않습니다. 표 데이터 실무에서는 여전히 **트리 부스팅이 기본 1순위**이고, 작은 데이터엔 **선형·로지스틱 회귀**나 **TabPFN**이 더 나을 수 있습니다. 7장의 결론과 같습니다 — **데이터의 크기·구조에 맞는 모델을 고르는 것**이 핵심입니다.
:::

## 8-2. 시계열 분석의 변천사

지금까지 다룬 `plant_growth`는 **행 순서가 의미 없는 표 데이터**였습니다. 반면 **시계열(time series)** 은 값에 **시간 순서**가 있어, "다음에 무엇이 올까"를 예측(forecasting)하는 것이 핵심입니다. 순서가 정보를 담기 때문에 표 데이터와는 다른 계열의 기법들이 발전해 왔습니다.

::: tip 시계열이 표 데이터와 다른 점
표 데이터는 행을 섞어도 되지만, 시계열은 **순서를 섞으면 정보가 파괴**됩니다. 그래서 "과거 값이 미래 값에 어떻게 이어지는가"를 다루는 별도의 방법론이 필요합니다.
:::

### ① 전통 통계 기법 — ARIMA · SARIMA · ARIMAX

시계열 분석의 고전으로, 통계학에 뿌리를 둡니다. 핵심 아이디어는 **"미래는 과거 값과 과거 오차의 조합으로 설명된다"** 입니다.

- **ARIMA** — 세 요소의 결합입니다. **AR**(자기회귀, 과거 값을 참고) + **I**(차분, 추세를 제거해 안정화) + **MA**(이동평균, 과거 예측 오차를 참고). 기본이 되는 모형입니다.
- **SARIMA** — ARIMA에 **계절성(Seasonal)** 을 더한 것. 매년 여름마다, 매주 월요일마다 반복되는 주기적 패턴을 다룹니다.
- **ARIMAX** — 외부 변수(eXogenous)를 추가로 넣은 것. 예: 기온·프로모션·환율이 판매량에 주는 영향까지 함께 반영.

- **유래** — 1970년대 Box-Jenkins 방법론으로 체계화된 고전 통계 기법.
- **강점** — **해석이 명확하고 통계적 근거가 탄탄**. 데이터가 적어도 안정적.
- **한계** — **선형·정상성(통계적 성질이 시간에 따라 일정) 가정**에 묶여 복잡한 비선형 패턴에 약함.
- **주 활용처** — 수요·재고 예측, 경제·금융 지표 예측, 데이터가 길고 패턴이 비교적 규칙적인 경우.

### ② 머신러닝 접근 — Prophet, XGBoost/LightGBM

시계열을 **"특성(feature)이 있는 예측 문제"** 로 바꿔 머신러닝으로 푸는 흐름입니다.

- **Prophet** — Meta(페이스북)가 공개한 예측 도구. 시계열을 **추세 + 계절성 + 휴일 효과**로 **분해**해 다룹니다. 설정이 간단하고 결측·이상치에 강해, **통계 지식이 적어도 실무에서 쓰기 쉽습니다.**
- **XGBoost / LightGBM** — 표 데이터의 그 부스팅(8-1)을 시계열에 적용합니다. **시점·요일·과거값(lag)·이동평균** 같은 것을 특성으로 만들어 넣으면, 비선형 관계와 외부 변수를 유연하게 학습합니다.

- **강점** — 전통 통계보다 **비선형·다변량 관계를 유연하게** 다룸.
- **한계** — 시간 순서 자체를 직접 모델링하기보다 **특성 공학(lag·날짜 특성 만들기)에 의존**.
- **주 활용처** — 여러 외부 변수가 얽힌 수요 예측, 휴일·이벤트 효과가 큰 매출 예측.

### ③ 딥러닝 — RNN/LSTM에서 Transformer로

순서 자체를 신경망으로 학습하는 흐름입니다.

- **RNN / LSTM** — **RNN**은 과거 정보를 다음 단계로 넘기며 **순차적으로** 처리하는 신경망인데, 시퀀스가 길면 앞쪽 정보를 잊는 문제가 있습니다. **LSTM**은 "기억할 것/잊을 것"을 조절하는 게이트를 넣어 **더 긴 패턴을 기억**하도록 개선한 RNN입니다. 다만 순차 계산이라 느리고, 아주 긴 의존성엔 여전히 약합니다(주로 GPU로 학습).
- **N-BEATS · PatchTST · TFT** — **Transformer/전용 구조** 계열. 자연어에서처럼 **어텐션으로 멀리 떨어진 시점 간 관계를 병렬로** 학습합니다. **PatchTST**는 시계열을 조각(patch)으로 나눠 트랜스포머에 넣고, **TFT**(Temporal Fusion Transformer)는 여러 변수와 미래 정보를 함께 다루며 **해석 가능성**까지 제공합니다.

- **강점** — 복잡한 비선형·장기 패턴, 다변량 관계를 강하게 학습.
- **한계** — **많은 데이터와 학습 비용**이 필요. 데이터가 적으면 ①·②가 더 나을 수 있음(7장의 교훈과 동일).
- **주 활용처** — 데이터가 풍부한 대규모 수요·전력·트래픽 예측.

### ④ 파운데이션 모델 — TSFM (시계열 파운데이션 모델)

가장 최신 흐름으로, **대량의 시계열로 미리 학습한 큰 모델을 재학습 없이 예측에 쓰는** 방식입니다(표 데이터의 TabPFN과 같은 발상).

- **TimesFM** — Google이 방대한 시계열로 사전학습한 예측 전용 모델. 처음 보는 시계열도 **제로샷(추가 학습 없이)** 으로 예측합니다.
- **Chronos** — 시계열 값을 **"언어처럼 토큰화"** 해 언어모델 방식으로 다음 값을 생성(언어모델과 거의 같은 구조를 시계열에 적용).
- **Moirai** 등 — 다양한 주기·도메인의 시계열을 한 모델로 아우르려는 범용 예측 모델.

- **강점** — 데이터가 적거나 새로운 영역에서도 **학습 없이 바로** 예측.
- **의미** — "시계열마다 모델을 새로 만든다"는 전제를 깬, 시계열판 파운데이션 모델.

### TabPFN과 TSFM — 같은 뿌리

표 데이터의 **TabPFN**과 시계열의 **TSFM**은 겨냥하는 데이터는 다르지만, **"대규모 사전학습 + 재학습 없는 예측(인컨텍스트 학습)"** 이라는 **같은 설계 철학**을 공유합니다.

| | TabPFN | TSFM (TimesFM·Chronos 등) |
|---|---|---|
| 대상 | 표(행=샘플) | 시계열(시간 순서) |
| 과제 | 회귀·분류 | 예측(forecasting) |
| 공통점 | 트랜스포머 기반 · 사전학습 · **재학습 없이 예측** | 좌동 |

실제로 두 세계가 만나고 있습니다 — 시계열을 표 형태 특성으로 바꿔 **TabPFN으로 시계열을 예측**하는 연구도 나왔습니다. 즉 **"파운데이션 모델 + 인컨텍스트 학습"** 이라는 뼈대가 데이터 종류를 넘나들며 번지는 것이 지금의 큰 흐름입니다.

::: warning 시계열에서도 원칙은 같습니다
최신 TSFM이 항상 최고는 아닙니다. 데이터가 짧거나 패턴이 단순하면 ARIMA·Prophet 같은 전통 기법이 더 정확하고 효율적일 수 있습니다. **데이터의 길이·주기·복잡도에 맞는 기법을 고르는 것**이 핵심입니다.
:::

## 8-3. 아직 다루지 않은 분석들 — 지도학습 너머

Module 1~7은 대부분 **지도학습**(정답을 주고 회귀·분류를 학습)이었습니다. 하지만 데이터 분석에는 정답 없이 구조를 찾거나, 다른 질문에 답하는 방법들이 많습니다. 여기서는 대표적인 계열을 **"무엇이고 언제 쓰나"** 중심으로 짧게 훑습니다.

::: tip 이 절의 목적
각 기법을 깊게 배우기보다, **"이런 도구가 있다"는 지도**를 그리는 데 목적이 있습니다. 실제 문제를 만났을 때 "이건 어떤 계열의 문제구나"를 알아채는 것이 첫걸음입니다.
:::

### ① 차원 축소 (Dimensionality Reduction)

변수(열)가 너무 많을 때, **정보를 최대한 유지하며 변수 개수를 줄이는** 방법입니다. 대표적으로 **PCA(주성분 분석)** 가 있고, 시각화용으로 **t-SNE·UMAP** 을 씁니다.

- **언제** — 특성이 수십·수백 개라 시각화·계산이 어려울 때, 또는 변수 간 중복(다중공선성)을 정리할 때.
- **예** — 고차원 데이터를 2차원으로 눌러 산점도로 한눈에 보기.

### ② 군집화 (Clustering)

정답 라벨 없이 **비슷한 데이터끼리 자동으로 묶는** 비지도학습입니다. 대표적으로 **K-Means, 계층적 군집, DBSCAN** 이 있습니다.

- **언제** — "고객을 몇 개 그룹으로 나눌 수 있나?"처럼 **미리 정해진 정답이 없을 때**.
- **분류와의 차이** — 분류는 정답(개화 Y/N)을 주고 배우지만, 군집화는 정답 없이 구조를 발견합니다.

### ③ 연관규칙 분석 (Association Rule Mining)

항목들 사이의 **"함께 나타나는 규칙"** 을 찾습니다. "장바구니 분석"으로 유명합니다.

- **언제** — "A를 산 사람이 B도 사는가?" 같은 동시 발생 패턴을 찾을 때.
- **예** — `기저귀 → 맥주`처럼, 함께 구매되는 상품 조합 발견(Apriori·FP-Growth 알고리즘).

### ④ 생존 분석 (Survival Analysis)

**"어떤 사건이 일어나기까지의 시간"** 을 다룹니다. 일반 회귀와 달리, 아직 사건이 안 일어난 데이터(중도절단)도 함께 씁니다.


- **언제** — 고객 이탈까지의 시간, 기계 고장까지의 시간, 환자 생존 기간 등.
- **대표** — Kaplan-Meier 곡선, Cox 비례위험 모형.

### ⑤ 이상 탐지 (Anomaly Detection)

**정상에서 크게 벗어난 소수의 데이터**를 찾습니다(2장에서 본 이상치 개념의 본격 버전).

- **언제** — 사기 거래, 설비 불량, 침입 탐지처럼 **비정상이 드물고 중요할 때**.
- **대표** — Isolation Forest, One-Class SVM, 오토인코더 기반 탐지.

### ⑥ 인과 추론 (Causal Inference)

**"상관이 아니라 원인"** 을 규명하려는 분야입니다. 4장의 "상관 ≠ 인과"를 본격적으로 다룹니다.

- **언제** — "이 정책이 매출을 **올렸는가**?"처럼 개입의 효과를 알고 싶을 때.
- **대표** — A/B 테스트(무작위 실험), 성향점수 매칭, 이중차분법(DID). 요즘 특히 주목받는 분야입니다.

### ⑦ 자기지도 학습 (Self-Supervised Learning)

**라벨 없는 대량 데이터**에서, 데이터 자체로부터 문제를 만들어 학습합니다(예: 문장의 다음 단어 맞히기). 오늘날 대규모 언어모델과 파운데이션 모델(8-1·8-2의 TabPFN·TSFM)의 **핵심 학습 방식**입니다.

- **언제** — 라벨을 붙이는 비용이 큰데 데이터는 많을 때.
- **의미** — "정답을 사람이 일일이 달지 않아도 학습한다"는 점에서, 요즘 트렌드의 근간이 되는 방식입니다.

::: warning 지도학습이 전부가 아닙니다
문제에 따라 정답(라벨)이 아예 없거나, "예측"이 아니라 "그룹 발견·원인 규명·이상 탐지"가 목적일 수 있습니다. **문제의 종류를 먼저 파악하고 그에 맞는 계열을 고르는 것**이, 특정 모델을 잘 쓰는 것보다 중요합니다.
:::

## 8-4. 정리 — 무엇을 언제 쓸 것인가

Module 8에서 표 데이터(8-1)와 시계열(8-2)의 변천사, 그리고 지도학습 너머의 분석들(8-3)을 훑었습니다. 전체를 관통하는 메시지는 하나입니다 — **"최신이 곧 최고는 아니다."**

### 발전의 공통 방향

표 데이터든 시계열이든, 발전의 큰 줄기는 같았습니다.

- **통계 규칙 → 머신러닝 → 딥러닝 → 파운데이션 모델**
- 뒤로 갈수록 "사람이 규칙·특징을 많이 정하던 방식"에서 "데이터로부터 스스로 학습하는 방식", 나아가 "**사전학습한 큰 모델을 재학습 없이 가져다 쓰는 방식**"으로 옮겨갔습니다.

하지만 **새 방법이 옛 방법을 폐기한 것은 아닙니다.** 선형회귀도, ARIMA도 지금도 현역입니다 — 상황에 맞으면 가장 좋은 선택이기 때문입니다.

### 문제 유형부터 파악하기

좋은 분석의 첫걸음은 모델 고르기가 아니라 **"이게 어떤 종류의 문제인가"** 를 아는 것입니다.

| 질문 | 문제 유형 | 
|---|---|
| 연속값을 예측 | 회귀 |
| 범주를 예측 | 분류 |
| 시간 순서로 미래 예측 | 시계열 예측 |
| 정답 없이 그룹 찾기 | 군집화 |
| 변수가 너무 많음 | 차원 축소 |
| 드문 비정상 찾기 | 이상 탐지 |
| 원인을 알고 싶다 | 인과 추론 |
| 사건까지 걸리는 시간을 알고 싶다 | 생존 분석 |

### 모델 선택의 실전 기준

같은 문제 유형 안에서 어떤 모델을 고를지는, **데이터와 목적**이 결정합니다.

- **데이터 크기** — 작으면 단순 모델(선형·트리)이나 TabPFN이 유리. 딥러닝은 데이터가 많아야 제값.
- **데이터 구조** — 관계가 선형에 가까우면 선형모델로 충분(6장 결과). 복잡하면 부스팅·딥러닝.
- **목적** — 성능이 전부가 아니라 **해석**(선형모델)·**속도**(LightGBM)·**재학습 없는 배포**(파운데이션 모델)가 더 중요할 수 있음.
- **실무 1순위** — 표 데이터는 여전히 **트리 부스팅(XGBoost·LightGBM·CatBoost)** 이 기본 출발점.

::: tip 이 가이드의 결론
우리는 통계 검정부터 딥러닝까지 왔지만, 매번 확인한 교훈은 같았습니다 — **데이터를 먼저 이해하고, 그 구조와 목적에 맞는 도구를 고르는 것.** 화려한 최신 기법을 아는 것보다, "언제 무엇을 쓸지" 판단하는 눈이 데이터 분석의 핵심입니다.
:::
